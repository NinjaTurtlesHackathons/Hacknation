# LaTeX-Fassung des Bell-Papers

`main.tex` ist eine eigenständige Datei: Literatur steht inline, Standardpakete aus TeX Live.
Kompilieren: `pdflatex main.tex` zweimal ausführen, oder die Datei bei Overleaf hochladen.

- Jede nummerierte Aussage ist in Anhang C auf ihre Prüfer-Claims zurückgeführt (`../paper_belege.json`).
- Zahlen, die Q eingrenzen, sind nach außen gerundete Werte des Prüfers.
- Jede Referenz ist per Crossref (`../references_crossref.json`) bzw. über den Scout mit wörtlichem Zitat (`research/kb/bell/`) belegt.
