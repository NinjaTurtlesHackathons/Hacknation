# Assumptions
- TDC snapshot is the benchmark distribution, not prospective clinical distribution.
- Scaffold split is one operational definition of extrapolation; acyclic molecules share empty scaffold.
- Twenty seeds are algorithm/split sensitivity, not twenty independent assays.
- Target transformations and assay heterogeneity constrain mechanistic interpretation.
- Descriptor gain, if any, is associative predictive evidence; feature importance is not a causal chemical explanation.
- Public test labels require procedural isolation; local code is not a secure enclave.
- No training-corpus contamination guarantee for LLMs; neutral identifiers test a narrower condition.
- Literature existence verification does not reproduce published results.
