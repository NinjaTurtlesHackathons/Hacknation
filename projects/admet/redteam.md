# Independent ADMET red-team review

Reviewed code and persisted numeric artifacts, without using project motivation or agent interpretations. Ran read-only checks with `work/admet-venv/bin/python`. Only this report was written. No production code, data, predictions, seal, or logs were changed; adversarial tests used memory-only monkeypatches. Findings distinguish current artifact correctness from assurance gaps in the default framework.

## 1. Split alignment and scaffold leakage

PASS for the three modeled endpoints across all 20 seeds. For each cached split, train and validation index sets were disjoint and together covered every source row. Every persisted validation seed/method group had exactly the cached validation row sequence; its targets matched the source targets. All 100 seed/method groups per endpoint were present. Independently rescored MAEs matched logged values within 1e-12. Both canonical-molecule and Murcko-scaffold intersections between train and validation were zero for every split, including empty scaffolds. Independently recomputed train_val/test intersections were also zero for the three modeled endpoints. All 44 source-file hashes matched provenance.

Validation tables contained 192,620 / 42,000 / 9,100 rows for AqSolDB / lipophilicity / Caco2 respectively. The apparent validation fraction should not be described as an exact row fraction: scaffold grouping can produce imbalanced fold sizes, particularly for AqSolDB.

## 2. Scoring, tamper resistance, and tolerances

PASS on currently stored artifacts. All 312 frozen file hashes matched seal.json. Reloading seed-1000 models reproduced all five methods on all three endpoints to maximum absolute discrepancy 8.9e-16. Correct numerical claims passed; a forged tolerance field and nonfinite claimed value were rejected. Fixed absolute tolerance is 1e-6 and is not agent-controlled.

ACTIONABLE assurance gap: the ADMET adapter computes from prediction CSVs without checking seal hashes, source-row targets, expected seed/method counts, or persisted model agreement. A memory-only substitution changing Caco2 combined predictions to y + 0.1 caused `DOMAIN.check` to accept a claimed combined MAE of 0.1. This proves that numerical recomputation is not independent artifact authentication. An attempted exact-zero substitution was rejected indirectly because the ratio routine forbids a zero denominator; positive substitutions pass. Protect the artifact trust boundary by running source-grounded validation and checking an immutable external digest manifest before certifying claims. The present hashes and independent reproduction support the present numbers, not a general claim of tamper-proof verification.

`validate.py` skips missing prediction files and only checks uniqueness, finite values, and MAE consistency for files present. It does not assert a full seed/method Cartesian product, expected row set, or source target correspondence. Current complete tables passed stronger independent checks, but the validator itself can certify incomplete tables. Make required artifacts and group/row completeness explicit before treating its passed flag as a certificate.

## 3. Invalid structures and repeated-seed inference

PASS for explicit handling observed in code and data. Invalid training SMILES were rejected. Allowed invalid structures produced finite fallback features. Test data had exactly two invalid structures in AqSolDB and none in the other endpoints. Persisted test predictions had 100 groups per endpoint and exact test source row/target alignment. AqSolDB tables recorded 200 invalid rows (two source structures multiplied by five methods and twenty seeds). The invalid fallback branch assigns the corresponding training median and similarity zero. No biological interpretation should be attached to those rows.

LIMITATION / paper constraint: the twenty seeds repeatedly reuse a fixed dataset. AqSolDB used 38,524 validation-row appearances from 7,889 distinct rows (mean 4.883 uses); lipophilicity 8,400 from 3,074 (2.733); Caco2 1,820 from 676 (2.692). Paired bootstrap intervals and sign-flip p values describe variation over these selected random scaffold partitions conditional on this dataset and pipeline. They do not establish independent molecular, clinical, biological, or external-dataset replication; neither ordinary independent-observation uncertainty nor broad generalization follows. Seed-level conditional randomization interpretation additionally needs its exchangeability assumptions stated. Do not present BH rejection as clinical significance or novelty. No population-level corrected resampling analysis was executed.

## 4. Default red-team and sentence gates

CONFIRMED framework weakness: `asd.writer.check` accepted all of these unsupported examples with no issues: `The system cures cancer.`; `Combined MAE is 0.9043293224732023 and proves clinical safety [C-test].`; `There were 4 independent clinical trials.`; `# This treatment cures 900 patients`; and a false shuffled-model claim reusing the supported combined-MAE number. The supplied C-test was itself marked challenged. The checker matches numeric token membership, exempts numbers 1-4, skips headings, and does not verify semantic entailment or claim status. Thus a zero-violation sentence log cannot prove paper truth, correct attribution, or absence of unsupported qualitative claims. Review each factual sentence manually against source evidence; filter challenged/hypothesis claims and explicitly qualify unverified interpretations.

CONFIRMED framework weakness: simulated red-team LLM failure returned an empty result list; the lab loop interprets absence of passing counterchecks as confirmed. A deliberately unrelated true anchor was recorded as a passing challenge. The mechanism checks arithmetic truth of submitted counterchecks but not whether they logically contradict the original claim. Treat unavailable/empty red-team output as unreviewed, not independently cleared; record the original claim and an explicit contradiction relation for each valid counterexample. `paper.claims_of` additionally assigns computed_rigorous to default red-team records despite their free-text ideas being unverified. Do not transfer that label to the scientific assertion.

## Review boundary

This review establishes source/prediction alignment and lack of scaffold/canonical overlap for the three modeled endpoints, all 60 validation partitions, current source/manifest consistency, and a sample of persisted-model reproducibility (seed 1000). It does not prove historical preregistration timing, absence of prior test exposure, clinical validity, novelty against literature, authenticity of upstream benchmark labels, independence of seeds, correctness of every training fit, or semantic truth of an eventual manuscript. All seed-1000 models were reloaded, but no full retraining was performed. Test scores were not used to propose model changes. The final manuscript needs a separate evidence-by-sentence audit.
