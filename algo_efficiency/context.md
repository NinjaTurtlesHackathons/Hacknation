# Context: algo_efficiency (rigorous-innovation, Full mode: team of 4, 21 h)

## Frame (Phase 0)
- **Assignment:** Algorithms and Efficiency. (1) Attention in subquadratic time (fine-grained complexity shows when this is provably impossible), and quantization/sketching/low-rank methods with error bounds. (2) Speculative decoding with optimality proofs and KV-cache compression. Nothing outside this scope.
- **Goal:** a paper generated by the verifier-gated lab in which every statement is verified (project CLAUDE.md).
- **Jury type:** Quant/Science (challenge #3 "Agentic Scientific Discovery"; jury judges method, validation, evidence). Rubric as given in the project CLAUDE.md: agents research, form hypotheses, plan and run experiments, learn from results, decide the next experiment; claims are checked.
- **Primary metric (one number):** number of research questions of `questions.json` resolved by a claim that passed the domain verifier, out of 7. Coverage metric: certified cells per table (degree table 15 cells, gamma table 24 cells, multi-draft instances).
- **Sub-metrics per area:** (A) degree saving d_Taylor / d* and polynomial-method rank C(h + d*, d*) vs n; (B) acceptance gap opt - rrs (exact); (C) error ratio vs the recent-window baseline (statistical).
- **Baselines (dumbest working solutions):** (A) Taylor polynomial; (B) rrs_iid (deployed multi-draft verification) and draft length chosen by grid search in floating point; (C) sliding window (`recent`) and `random`.
- **Verifier (the product):** exact rational arithmetic; max-flow = min-cut certificates; Remez + interval arithmetic + de la Vallee Poussin certificates; paired permutation tests with BH on fixed seeds. Self-test with near-boundary true/false claims and rule violations (24 cases).
- **Canonical reformulation:** (A) weighted Chebyshev (minimax) approximation; (B) maximal coupling / optimal transport with membership cost = bipartite max-flow; (C) budgeted subset selection under a stochastic attention model.
- **Modules (section 9):** F (mathematics: exact statements, oracles, negative controls) and C (optimisation: LP/flow formulation, dual certificate). KV part uses the statistical battery (section 7).
- **TRIZ contradiction:** we want speed (fewer target-model calls, fewer attention entries, smaller cache) without changing the output distribution or exceeding a certified error, i.e. efficiency vs. exactness.
- **What everyone silently assumes (assumption register, details in assumptions.md):** that multi-draft verification rules in use are near-optimal; that the polynomial method is a practical subquadratic attention algorithm; that eviction heuristics are close to the best possible cache.

## Model (Mathematisieren block)
1. **Quantities.**
   - B > 0: bound on attention logits |<q_i, k_j>| (dimensionless); eps in (0, 1/2]: relative entrywise error; d in N: polynomial degree; h in N: head dimension; n: context length.
   - p, q in Delta_V: target and draft distributions on V <= 8 tokens, exact rationals; k in {1..4}: number of drafts; alpha in [0, 1): i.i.d. acceptance; c > 0: draft/target cost ratio; g in N: draft length.
   - KV: budget b < n; relative output error ||o - o_b|| / ||o||, synthetic model (assumption A5).
2. **Objectives.** (A) d*(B, eps) = min{d : min_{deg P <= d} max_{|x| <= B} |1 - P(x) e^{-x}| <= eps}; rank R = C(h + d*, d*). (B) alpha*(p, q, k) = max over lossless couplings pi of P_pi(Y in draft set); compare with rrs acceptance; g* = argmax_g (1 - alpha^{g+1}) / ((1 - alpha)(g c + 1)). (C) minimise expected relative output error at budget b.
3. **Constraints.** Losslessness: output marginal = p exactly. Coupling marginals: draft-set law and p. Degree <= 48, B <= 32, V <= 8, k <= 4 (verifier limits).
4. **Axioms / lemmas with status.**
   - L1 Losslessness of standard, rrs_iid, rrs_wor (k <= 4): **verified exactly on every tested instance; known theorem** (2211.17192, 2302.01318).
   - L2 Single-draft optimum alpha*(p, q, 1) = 1 - TV(p, q) = sum min(p, q): **verified exactly** (max-flow = cut on every instance).
   - L3 Cut formula alpha*(p, q, k) = min_H [1 - p(H) + P(draft set meets H)], iid case min_H [2 - p(H) - (1 - q(H))^k]: **proved** (max-flow/min-cut on the bipartite set graph; extension of partial couplings) and **certified numerically exactly** on all instances (flow = cut).
   - L4 opt_wor >= opt_iid: **proved by hand** (conditional avoidance probability (q(not H) - u)/(1 - u) <= q(not H)); not machine-checked (no Lean in the sandbox); 0 counterexamples in 3,000 exploratory instances.
   - L5 rrs_wor >= rrs_iid: **open** (0 counterexamples in exploratory search; confirmatory search preregistered, H-AE2).
   - L6 Monotonicity: d*(B, eps) non-decreasing in B and in 1/eps: **observed** on the certified table (no proof needed for the claims; used only as a sanity check).
   - L7 d*(B, eps) <= Taylor degree: **holds by definition** (Taylor polynomial is admissible); used as theory check T2.
   - L8 Rank of the polynomial-method factorisation = dimension of polynomials of degree <= d in h variables = C(h + d, d): **standard** (monomial count).
5. **Checks.** Extreme cases: p = q gives acceptance 1 (exact); point-mass p; k = 1 reduces to L2; B -> 0 gives d* = 0 or 1. Orders of magnitude: E_d decays super-geometrically once d > e B / 2.
6. **Remaining assumptions:** assumptions.md.
