{\Large\bfseries Verifier-Gated Discovery Lab}\\[2pt]{\small Agents propose, Omnigent orchestrates, only a code verifier accepts. \quad Commit 123e300}\par\medskip
\section{Challenge and users}
Agentic scientific discovery (Databricks challenge). Users: researchers who need results they can trust without re-checking every line.\par
\section{Tools}
Omnigent (orchestration, policies), Claude via the Claude Code CLI, Python verifiers (sympy, python-flint, scipy), MCP server, LaTeX.\par
\section{What worked}
The verifier-gated loop: 3 certified and 2 rejected claims in one run; a surprise reopened an assumption and changed the plan; the family classification moved to 50 / 14 / 24.\par
\section{What was hard}
Making the agents' claims exactly as strong as the evidence; keeping tolerances inside the verifier; parallel agents writing one state file (fixed with a file lock).\par
\section{Time use}
Recorded run 6 min, of which 0 min waiting for human approval; agents/LLM at least 98 s, verifier at most 129 s, experiments at most 362 s.\par
\section{Results}
14 exactly certified violations of the proofreading bound among 88 topologies, 11 of them new in the recorded Omnigent runs; trust benchmark: lab 0.0\% false vs. Claude alone 36.1\%.\par
\section{Measured speedup}
Replay, 16 paired seeds: 3.34x vs. a hand-written heuristic (95\% CI 2.81 to 4.16, p = 1.5e-05), 4.76x vs. random (95\% CI 2.92 to 7.23, p = 0.00017); vs. no feedback 1.13x (not significant). Result-to-decision latency median 24 s (n = 4, one run). No comparison with a human or a real laboratory was measured.\par
