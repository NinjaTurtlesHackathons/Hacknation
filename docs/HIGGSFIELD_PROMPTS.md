# Higgsfield: copy-and-paste prompts (60 s video "Mia")

For each shot, two steps in the Higgsfield web app:

1. **Image** (Soul, format 16:9): paste the image prompt and generate.
2. **Video** (Image to Video, 5 s): use that image, paste the video prompt, and put the negative prompt in the negative prompt field.

**Negative prompt (the same for every video):**
```
text, letters, numbers, watermark, logo, garbled writing, faces on the light figures, extra fingers, distorted hands, purple neon, cartoon
```

**Tip:** If the app has a "Character" for Mia, select it for shots 01, 02 and 13 so her face stays the same.

Overlays (text, numbers, logo) go in during the edit; see docs/HIGGSFIELD_STORYBOARD_MIA.md.
