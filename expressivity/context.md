## Canonical reformulation
"Which finite automata can a single layer of a given recurrence class simulate exactly, for inputs of every length?" is the standard problem of **representing a finite transformation monoid/group by matrices from a constrained family**. For linear RNNs with transitions `I + (rank <= k)` (DeltaNet k = 1, DeltaProduct k) this is the classical question of **finite linear groups generated by elements with a fixed space of codimension <= k** (reflections for k = 1). Standard tools: character theory (dimension of fixed spaces), Cartan–Dieudonné (minimal number of reflections), finite semigroup theory (minimal ideal, maximal subgroups), Krohn–Rhodes / Barrington for the circuit side. Their assumptions: exact arithmetic, finite groups, real orthogonalisable representations.

## Primary metric (one number) and coverage
- **Primary metric:** prediction accuracy of an algebraic predictor on the preregistered grid of (architecture, task) cells, where a cell's outcome is whether the majority of 20 seeds length-generalises (prereg.md). Our predictor: *success iff the layer's algebraic budget covers the task's invariant* (k >= h* for Householder products; abelian/involution conditions for diagonal recurrences). Baselines (dumbest working predictors): B1 "circuit class" (solvable group -> success, non-solvable -> failure, the current state-tracking heuristic), B2 "abelian -> success", B3 "smaller group -> success".
- **Coverage metric:** number of (group, alphabet) pairs in the atlas for which the exact invariant h* is determined (matching certified lower and upper bound), out of all pairs considered.

## Verifier (the product)
Exact arithmetic over Q and Q(sqrt 5) for matrix certificates (closure of the generated matrix group, consistency of the induced map onto G, invariant Gram matrix, rank of `M - I`, explicit Householder factorisations multiplied out exactly); exact group computations on permutations; character tables computed twice (own numerical Burnside–Dixon implementation with an integrality margin, and GAP with exact cyclotomics); Lean 4 + Mathlib for the rank lemma; paired permutation tests and Benjamini–Hochberg for trained models, evaluated by the verifier on its own held-out seeds.

## TRIZ contradiction
We want a recurrence that is cheap per token (few rank-one updates, diagonal if possible) **and** tracks arbitrary finite state exactly for unbounded length; cheapness forces commuting or low-rank transitions, exact tracking of non-abelian structure forces non-commuting, higher-rank ones.

## What everyone silently assumes (assumption register, details in assumptions.md)
1. That circuit complexity (solvable vs. non-solvable, TC0 vs. NC1) also orders the difficulty of state tracking for *recurrent* linear architectures.
2. That the cost of tracking a group is a property of the group alone, not of the input alphabet.
3. That a layer must represent the group itself (faithfully), rather than a larger group mapping onto it.
4. That more Householder factors are needed for larger or "harder" groups (S5 vs. A5 vs. Z60).

## Model (Mathematisieren block)
1. **Quantities.**
   - G finite group, Sigma ⊆ G \ {e} a generating input alphabet; word w = s_1 ... s_T, target g_t = s_t s_{t-1} ... s_1 (left action), all t <= T, all T.
   - One layer: state h_t ∈ R^{d x m}, update h_t = A(s_t) h_{t-1} + B(s_t), readout y_t = phi(h_t) with arbitrary phi. Transition families: DIAG+ (diagonal, entries in [0, 1]), DIAG± (diagonal, entries in [-1, 1]), CDIAG (complex diagonal, |lambda| <= 1), HH_k (`A = prod_{j<=k} (I - beta_j u_j u_j^T)`, beta_j ∈ [0, 2], ||u_j|| = 1).
   - k ∈ N: Householder budget per token; d: state dimension.
   - h(G, Sigma) := min over faithful real representations rho of G of max_{s ∈ Sigma} rank(rho(s) - I).
   - h*(G, Sigma) := min over finite groups H, surjections pi: H -> G, lifts t_s ∈ H with pi(t_s) = s generating H, and faithful real representations rho of H, of max_s rank(rho(t_s) - I).
2. **Objective.** For each family and (G, Sigma): decide whether an exact one-layer realisation exists (for all lengths), and for HH_k compute the minimal k, i.e. h*(G, Sigma).
3. **Constraints.** Transitions depend on the current token only (no short convolution), one layer, exact real arithmetic, finitely many reachable states.
4. **Axioms / lemmas with status.**
   - L1 Rank lemma: a product of k matrices of the form I - (rank <= 1) satisfies rank(M - I) <= k. **Status: proved by hand (rank subadditivity); Lean 4 + Mathlib proof planned (proved_lean target).**
   - L2 Compression lemma (necessity): every finite-state one-layer realisation of (G, Sigma) with transitions `I + rank <= k` yields (H, pi, t_s, rho) as in the definition of h* with rank(rho(t_s) - I) <= k. Hence k >= h*. **Status: proved by hand (minimal ideal of the finite transition monoid, idempotent word u, compressed maps A_u A_s restricted to the column space); open for red-team review.**
   - L3 Sufficiency: any (H, pi, t_s, rho) with rank <= k gives an exact HH_k realisation with beta ∈ {0, 2} in dimension dim rho. **Status: proved by hand (invariant inner product + Cartan–Dieudonné, generic initial state, finite readout); every concrete instance is re-verified by the code certificate (closure + consistency + rank + explicit factorisation).**
   - L4 Order lemma: if some s ∈ Sigma has order >= 3 then h* >= 2. **Status: proved by hand (a finite-order real matrix with rank(M - I) = 1 is a reflection, order 2; the order of a lift is a multiple of the order of its image).**
   - L5 Diagonal families: DIAG± realises (G, Sigma) iff G is an elementary abelian 2-group; CDIAG iff G is abelian; DIAG+ realises no nontrivial group. **Status: proved by hand via L2 (compressed maps commute; real diagonal of finite order has entries ±1; nonnegative real of finite order is the identity); consistent with prior work (evidence.md).**
   - L6 Additivity: rank(rho1 ⊕ rho2 (g) - I) = sum of ranks; codim Fix rho(g) = dim rho - (1/|g|) sum_j chi(g^j). Hence h is computable from the real character table. **Status: standard (character theory).**
   - L7 Abelian cover: for abelian G, h*(G, Sigma) = 1 if all s ∈ Sigma are involutions, else 2 (track each symbol's count modulo its order). **Status: proved by hand (upper bound by construction, lower bound L4 and nontriviality).**
5. **Checks (extreme cases).** G trivial: h* = 0. G = Z2: h* = 1. Sigma containing an element of order >= 3: h* >= 2. Faithful h can be much larger than h* (Z2^k with full alphabet: h = k, h* = 1).
6. **Remaining assumptions:** assumptions.md (finite reachable state set, token-local transitions, one layer, exact arithmetic; trained models only approximate this).
