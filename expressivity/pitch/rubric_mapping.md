run them, learn from the results and decide on the next experiment. Jury type: Quant/Science (`expressivity/context.md`), so the
jury judges method, validation and evidence. Rule for this file: every row points to a file in the repository; nothing is claimed
that the file does not contain. Paths are relative to the repository root.
