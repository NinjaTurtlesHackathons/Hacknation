## Formal stage (skill 5.2): method transfer from finite reflection-group theory
The analogist's span (analogist_candidates.md): common theory T = (finite group H, generators t_s, faithful rho: H -> O(V),
epimorphism pi: H -> G with pi(t_s) = s, cost c = codim Fix). Source: finite reflection/rotation groups. Target: one-layer linear RNN.
Proof obligations in the target and their status:
- O1 H finite: **discharged** by the compression lemma L2 (finite reachable state set gives a finite group of compressed maps) and,
  for every certificate, by the exact closure computed in `realisation.verify`.
- O2 invariant inner product: **discharged** (averaging; the certificate checks P > 0 and R^T P R = P exactly).
- O3 field R: **discharged** (all certificates are over real cyclotomic fields; complex results are not transferred).
- O4 a start vector whose stabiliser lies in ker pi: **discharged** (generic vector, finite union of proper fixed subspaces; the
  certificate instead checks that the matrix -> group-element map is consistent, which is equivalent).
- O5 classification applied to the generating family, not the abstract group: **not used** (no classification theorem is transferred;
  only Cartan–Dieudonné, which is applied to each certified matrix and re-verified by an explicit factorisation).
- O6 reducible non-split rotation groups: **not applicable** (no k = 2 classification transferred).
Transfer class used: explicit source constructions give upper bounds (source -> target), re-verified in the target (skill 5.1:
"Neuprüfung im Ziel"); the lower bounds use only T1-T5-type facts (rank subadditivity, conjugation invariance, order of a
reflection), proved in the target itself. Stage: (constructions + elementary lemmas, epsilon = 0); no classification is claimed.

## Fallback
If a training cell predicted to succeed fails, it is reported as a learnability failure (prereg.md); if a certificate fails, the
cell is reported as "not certified", never as a value.
